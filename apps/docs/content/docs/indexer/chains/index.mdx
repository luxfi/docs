The Lux Network has 9 distinct chain types, each with its own consensus protocol and data model. The indexer has purpose-built adapters for each.

| Chain | Type | Consensus | Purpose |
|-------|------|-----------|---------|
| C | EVM | Nova | Smart contracts, DeFi |
| P | Linear | Nova | Validators, staking |
| X | DAG | Nebula | Asset exchange |
| A | DAG | Nebula | AI compute |
| B | DAG | Nebula | Bridge |
| Q | DAG | Nebula | Quantum |
| T | DAG | Nebula | MPC |
| Z | DAG | Nebula | ZK proofs |
| K | DAG | Nebula | KMS |
