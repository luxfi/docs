### DefaultNotifyContext

```go
func DefaultNotifyContext(duration time.Duration, cleanup func(func())) context.Context
```

DefaultNotifyContext returns a context that is marked done when signals indicating
process termination are received. If a non-zero duration is provided, the parent to the
notify context will be a context with a timeout for that duration.


### GetMetricValue

```go
func GetMetricValue(metrics NodeMetrics, name string, labels metric.Labels) (float64, bool)
```

GetMetricValue returns the value of the specified metric which has the
required labels.

If multiple metrics match the provided labels, the first metric found is
returned.

Only Counter and Gauge metrics are supported.
